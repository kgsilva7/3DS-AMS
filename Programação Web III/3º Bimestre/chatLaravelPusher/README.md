# Chat em Tempo Real com Laravel, WebSocket e Pusher

Este projeto é uma aplicação de chat em tempo real bidirecional desenvolvida como atividade prática. A solução utiliza o framework **Laravel 11**, autenticação de usuários via **Laravel Breeze**, interface de chat avançada via pacote **Chatify** e infraestrutura de WebSockets fornecida pelo **Pusher Channels**.

---

## 🛠️ Tecnologias Utilizadas

* **Framework PHP**: Laravel 11
* **Ambiente de Desenvolvimento Local**: XAMPP (Apache & MySQL)
* **Autenticação**: Laravel Breeze
* **Interface do Chat**: Chatify Package
* **Comunicação em Tempo Real (WebSocket)**: Pusher Channels
* **Gerenciadores de Pacotes**: Composer e NPM

---

## 📋 Pré-requisitos

* PHP >= 8.2
* Composer instalado
* Node.js e NPM instalados
* XAMPP (com serviços Apache e MySQL ativos)
* Conta no [Pusher](https://pusher.com/)
